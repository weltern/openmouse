HID++ probe

Dev-only tool. Enumerates every HID++ device behind a Logitech receiver (or connected directly by cable/Bluetooth) and dumps its full feature table. Nothing is written to the mouse — every request here is a read.

The two scan buttons walk the function ids of 0x19B0 HAPTIC, 0x19C0 FORCE SENSING BUTTON and 0x2251 WHEEL STATS — features Solaar names but nobody has decoded. The first stops at function 0x03, which by HID++ convention is still getter territory. The deep scan goes to 0x0F and can therefore call a setter with all-zero arguments; run the safe scan first so its output records anything a write would need to restore. 

Ready. Click “Pick a Logitech HID++ device” and choose your receiver
(or the mouse itself, if it is plugged in by cable or paired over Bluetooth).
